# Pixkit Background Remover

웹 이미지 배경을 AI로 제거하는 크롬 확장 프로그램.
100% 로컬 처리 — 파일이 서버로 전송되지 않음.

## 설치 방법

1. `pixkit-extension` 폴더 다운로드
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 토글 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭
5. `pixkit-extension` 폴더 선택

## 사용 방법

1. 웹페이지에서 이미지 우클릭
2. **"Pixkit: 배경 제거"** 선택
3. AI가 자동으로 배경 제거
4. 브러시로 세밀하게 다듬기 (지우개/복원)
5. PNG/JPG로 다운로드

## 사용 제한

- 하루 3회 무료 사용
- 매일 자정 초기화
- 무제한 사용: pixkit.app/remove-bg

## 에디터 단축키

| 키 | 기능 |
|----|------|
| E | 지우개 모드 |
| R | 복원 모드 |
| [ ] | 브러시 크기 조절 |
| Ctrl+Z | 실행취소 |
| Ctrl+Y | 다시실행 |
| 마우스 휠 | 줌 인/아웃 |
| 가운데 버튼 드래그 | 패닝 |

## 개발

editor-src.js를 수정한 후 번들 빌드:

```sh
sh pixkit-extension/build.sh
```
